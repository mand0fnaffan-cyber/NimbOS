# ⚡ NimbOS

> Powered by the Storm.

NimbOS is a custom Linux distribution based on Arch Linux,
built around a thunderstorm-inspired design and experience.

## 🌩️ Features

- Arch Linux base
- GNOME desktop
- Neon-green storm aesthetic
- Custom NimbOS branding
- Custom wallpapers
- Custom boot experience
- NimbOS utilities

## 💚 Why green?

The neon-green color is a tribute to KernelDust,
the Linux project that came before NimbOS.

## 🚧 Status

NimbOS is currently in development.
